## 这门课是什么

这不是一套“大而全”的 Python教程，只做一件事：**用最短的时间，把Python最核心的语法讲清楚**，让你能看懂、能改、能自己写一些小脚本。

- **7讲**：从“Python是什么”讲到面向对象，覆盖入门阶段最常用的语法。
- **13个视频，约78分钟**：每讲都短小，适合碎片时间看完。
- **课件可运行**：每讲都有 Jupyter Notebook，代码和输出都在，边看边改。
- **零第三方依赖**：示例只使用 Python 标准库，不需要装 pandas、numpy 等任何包。
- **中文讲解**：面向零基础、非科班、自学容易卡住的同学。

课程录制于2023年，环境为 **Python 3.8.5 + PyCharm**；示例语法在 Python 3.8 及以上版本都可以直接运行。

### 学完你将掌握

- Python 的特点、版本历史，以及它到底能做什么
- 数值、字符串、列表、元组、字典、集合六大类型，以及切片、格式化、去重
- `if` 条件判断、`for` / `while` 循环、`break` / `continue`
- 函数定义、参数传递、返回值、匿名函数
- 类、对象、继承、私有属性
- 一套可以继续往数据分析、爬虫、Web、自动化方向走的基础

## 5 天学习路线

| 天数 | 内容 | 建议 |
| :--: | --- | --- |
| Day 1 | 第 1–2 讲 | 先把环境装好，跑通 Hello World，约 1.5 小时 |
| Day 2 | 第 3 讲 | 数据类型是重点，边看边敲，约 3 小时 |
| Day 3 | 第 4–5 讲 | 条件 + 循环，自己写几个小练习，约 2.5 小时 |
| Day 4 | 第 6 讲 | 函数，试着把前面的代码封装成函数，约 1.5 小时 |
| Day 5 | 第 7 讲 | 面向对象，并复盘前四天的内容，约 2 小时 |

不用严格按 5 天来，按自己的节奏走即可。**看视频的时间只占一小部分，动手敲才是关键。**

## 快速开始

### 方式一：只想看课件

- 直接点开上表中的 **ipynb**，GitHub 会在浏览器里渲染出文字和代码输出。
- 想打印或离线看，下载对应的 **PDF**。
- 手机、平板上看，PDF 的排版会更舒服。

### 方式二：想运行代码

```bash
# 先 git clone 本仓库（或点 Code → Download ZIP 解压）
cd python-beginner/notebooks      # 解压后的目录名可能带 -main 后缀

python3 -m venv .venv
source .venv/bin/activate        # Windows 用：.venv\Scripts\activate

pip install notebook
jupyter notebook
```

浏览器会自动打开，点进对应讲次就能逐格运行。已经装过 Jupyter 的话，直接 `jupyter notebook` 即可。

> 不需要安装任何第三方库。课件里只用了 Python 标准库，`notebook` 只是用来打开 `.ipynb` 文件的工具。

### 方式三：在 PyCharm 里跟着敲

1. 用 PyCharm 打开 `notebooks/` 所在的文件夹；
2. 新建一个 `.py` 文件，把课件里的代码敲进去；
3. 右键 Run，或者在命令行执行 `python 文件名.py`。

> 注意：在 Jupyter 里直接写变量名就能看到值，在 PyCharm 里必须用 `print()` 才会输出。这是两种工具的区别，不是代码写错了。

## 阅读提示

- 每个代码块上方的注释会说明这段代码在做什么，建议**先自己敲一遍，再看输出**。
- 课件里故意保留了几个错误示例（比如 `if 1 = 1`、默认参数写在非默认参数前面），运行会报错——这是教学的一部分，不是课件坏了。
- 变量名、注释里的中文是为了方便理解；实际项目里建议用英文命名。
- 课件里的输出已经保存，不运行也能看到结果。
- 第 3 讲的代码格子比较多，建议按“数值 → 字符串 → 列表 → 元组 → 字典 → 集合”的顺序看。

## 常见问题

<details>
<summary><b>完全没基础，能看懂吗？</b></summary>

可以。这套课就是按“没写过代码”的前提录的，从安装开始讲，不默认你会任何编程语言。遇到不懂的名词，先跟着敲一遍，再回头理解。
</details>

<details>
<summary><b>需要先装 Anaconda 吗？</b></summary>

不需要。装一个 Python 解释器 + Jupyter Notebook 就够了；想写 `.py` 文件的话再装 PyCharm（免费版即可）。Anaconda 体积较大，入门阶段不是必需品。
</details>

<details>
<summary><b>课程用 Python 3.8.5，现在还能用吗？</b></summary>

能。课件里的语法在 3.8 及以上版本都通用。如果你是新装环境，建议直接装 3.10 或更高版本；3.8 已经停止维护，不建议再用于新项目。
</details>

<details>
<summary><b>为什么 Jupyter 里写 <code>a</code> 能出结果，PyCharm 里没反应？</b></summary>

Jupyter 会自动显示最后一个表达式的值，PyCharm 不会。在 `.py` 文件里要写成 `print(a)`。
</details>

<details>
<summary><b>课件里的图片显示不出来？</b></summary>

确认 `img/` 文件夹和 `.ipynb` 文件在同一层目录下（即 `notebooks/img/`）。如果只单独下载了某个 ipynb，图片会缺失，建议整仓下载。
</details>

<details>
<summary><b>视频和课件顺序对不上？</b></summary>

B 站合集里第 3 讲拆成了 6 个视频（数值、字符串、列表、元组、字典、集合），第 5 讲拆成了 2 个（for、while），所以是 13 个视频对应 7 讲课件。上表的“视频”列已经标好了每讲从第几 P 开始。
</details>

<details>
<summary><b>有课后作业吗？</b></summary>

没有单独的作业文件。建议每讲结束后自己加练：第 3 讲把每种类型的方法都敲一遍；第 4–5 讲写一个判断成绩等级、打印乘法表的小程序；第 6 讲把前面的代码封装成函数；第 7 讲试着给“学生 / 课程”建两个类。
</details>

<details>
<summary><b>可以转载，或者用于公司内训吗？</b></summary>

课件采用 MIT 协议，可以转载、修改，也可以用于内训，保留作者与出处即可。B 站视频的版权归作者所有，不在 MIT 授权范围内，请勿下载、搬运或二次上传。
</details>

<details>
<summary><b>发现课件有错误怎么办？</b></summary>

欢迎提 [Issue](../../issues/new/choose) 或直接发 PR，注明是哪一讲、哪个代码格。仓库里准备了“内容错误 / 代码问题”和“内容建议 / 改进”两个模板。错别字、代码跑不通、解释不清楚，都算有价值的问题。

<details>
<summary><b>学完接下来学什么？</b></summary>

按兴趣选一个方向继续：数据分析（pandas / matplotlib）、爬虫（requests / BeautifulSoup）、Web（Flask / Django）、自动化办公（openpyxl / python-docx）。无论选哪个，先把这套课的语法练熟，会省很多力气。
</details>
